# Pony Tutorial

> A tutorial for the Pony programming language.

The Pony Tutorial is a comprehensive guide to the Pony programming language, an object-oriented, actor-model, capabilities-secure language. It covers the type system, reference capabilities, generics, C FFI, testing, and more. The target audience is programmers with some experience in another language.
